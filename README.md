# news-image-20261123

Entry for [make.fun "Sum up 23 November's world news in one image"](https://make.fun/bounty/news-image-20261123).

![make.fun](https://img.shields.io/badge/make.fun-bounty-blue) ![contest](https://img.shields.io/badge/contest-news--image--20261123-purple) ![date](https://img.shields.io/badge/date-23_Nov_2026-green)

`main.py` copies the repository's pre-rendered `entry.png` (1024x1024) to `/output/entry.png`. No network; deterministic — both runs write identical bytes.

The image sums 31 verified stories of Monday 23 November 2026 across 7 regions, led by the COP31 collapse and the Ukrainian naval-drone sinking of a Russian warship off Libya. Sources: BBC World, Al Jazeera, NPR, The Guardian.
